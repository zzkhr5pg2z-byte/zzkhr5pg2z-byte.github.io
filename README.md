# Iron Perimeter

A first-person shooter that runs in the browser. Play it at **https://zzkhr5pg2z-byte.github.io**.

This copy is single player; online play with a friend works on the Claude-hosted version.

Built from `games/iron-perimeter` (`node build.mjs`, then the contents of `dist/`). Sky, textures and props
from Poly Haven (CC0); vehicles and buildings from Sketchfab (CC BY), credited in the game's menu and in
`models/SKETCHFAB_CREDITS.md`.
